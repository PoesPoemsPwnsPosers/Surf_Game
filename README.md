# Surf Game

An arcade surfing game for desktop browsers, phone browsers, and iOS and Android (Expo). Level 1: Venice Beach.

Play it: https://poespoemspwnsposers.github.io/Surf_Game/ (published from `main` by GitHub Actions).

```
npm install
npm run dev
```

```
npm test          # automated playtests: desktop, phone, and the mobile app's build
```

The mobile app is in [mobile/](mobile/README.md).

See [NOTES.md](NOTES.md) for what is built, the controls and what is left, and
[CREDITS.md](CREDITS.md) for assets and licenses.
